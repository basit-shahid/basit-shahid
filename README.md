## About

I'm **Basit**, a software engineering student in **Lahore, Pakistan**, focused on **Laravel, PHP, and backend development**. I enjoy turning a messy problem into a clear model, then building the interfaces and logic that make it useful.

My projects span publishing, file sharing, and desktop utilities. Alongside them, I practice **C++, Java, and data structures and algorithms** to understand the decisions underneath the code.

**Currently exploring** &nbsp; REST APIs · database design · SOLID principles · trees, graphs & dynamic programming
